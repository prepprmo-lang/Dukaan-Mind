# DUKAAN MIND — AI-Powered Grocery Store & Demand Forecasting System

Think Smart. Sell Smart. Grow Smart.

Dukaan Mind is an end-to-end Python & Streamlit business intelligence and demand forecasting application designed for small-scale grocery shops and local Kirana stores in India.

## Quick Start in VS Code
1. `pip install -r requirements.txt`
2. `streamlit run app.py`

## Project layout
- `src/` - active Streamlit application and database modules
- `data/` - SQLite database and project data
- `assets/` - application media
- `models/` - generated model artifacts
- `archive/` - legacy modules not used by the active application
